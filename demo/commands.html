Command blocks: output as data.

Shells mark prompts, commands and exit codes with OSC 133. Wraith pins each mark in Ghostty's scrollback, so every command becomes a block you can list, copy and jump between. The blocks follow scrolling, reflow and trimming. Hover over a block to copy it. ⌘↑/⌘↓ (or Ctrl+Shift+↑/↓) jumps between prompts.
