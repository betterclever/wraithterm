03 · Where the time goes

Bytes in.
Pixels out. Nothing wasted.

  1. 01PTY bytes

    Writes in one microtask batch become one transfer and one acknowledgement.

  2. 02Worker

    Parsing and rendering stay off your app's main thread.

  3. 03libghostty-vt

    Ghostty's terminal engine, compiled from Zig to Wasm with ReleaseFast.

  4. 04Row snapshot

    Rows keyed by identity and contents. Moved rows are copied, unchanged rows skipped.

  5. 0520-byte cells

    Colors, flags and one glyph word: atlas slot, ink width, color bit.

  6. 06WGSL, two passes

    Backgrounds, then glyph quads sized to ink. Blank cells draw nothing.

04 · Two ways in

Keep your xterm code.
Or go full ghost.

Drop-inxterm.js 6.0 API
import { Terminal } from 'wraithterm/xterm';
import { FitAddon } from '@xterm/addon-fit';

const term = new Terminal({ fontSize: 14 });
term.loadAddon(new FitAddon());
term.open(element);
term.write('same API, WebGPU underneath');

xterm's parser and buffer, Wraith's renderer. Addons such as fit, search, serialize and web links keep working.

NativeGhostty in a worker
import { Wraith } from 'wraithterm';

const term = await Wraith.mount(element);
term.connect(new WebSocket(ptyUrl));
term.onResize(({ cols, rows }) => {
  // tell the PTY
});

Ghostty's terminal semantics, Kitty keyboard encoding and reflow, with the whole terminal off the main thread.
