# Freedoom and doomgeneric

The DOOM gameplay in `WraithOnGo` is the built-in `demo1` of
[Freedoom](https://freedoom.github.io/) 0.13.0 (`freedoom1.wad`, SHA-256 prefix
`7323bcc168c5a45f`). Freedoom is free game content compatible with the DOOM engine,

Redistribution and use are permitted under the conditions in Freedoom's
`COPYING.txt`. The film shows rendered frames with this credit; the WAD itself is
not redistributed.

Frames are rendered by [doomgeneric](https://github.com/ozkl/doomgeneric) (commit
`e257a09`, GPL-2.0) with Wraith's `doomterm` platform file
([capture/doomterm](../capture/doomterm/doomgeneric_term.c)). doomgeneric is built
and run locally as a tool to produce terminal output. Neither it, the WAD nor the
recorded streams are distributed in this repository. DOOM is a trademark of id
Software; this project is not affiliated with or endorsed by id Software.
